# Yapping Helper

Turn talking-head videos into short, captioned vertical clips with AI-selected hooks and payoffs.

## Features

- Upload MP4, MOV, or WebM videos to App Storage.
- Real speech transcription with word timestamps and AI-selected montage variations.
- Portrait H.264/AAC output, including HDR-to-SDR conversion.
- Six caption presets with burned-in captions and downloadable SRT/ASS subtitles.
- Optional **Upbeat** or **Chill** background music, adjustable volume, and automatic speech ducking.
- Optional gentle punch-ins and richer color.
- CSV export with clip metadata and MP4, SRT, ASS, and results links.
- Regeneration and confirmed deletion of the current job and its stored files.

See [CHANGELOG.md](CHANGELOG.md) for the latest additions.

## Project structure

- `artifacts/yapping-helper`: React/Vite frontend
- `artifacts/api-server`: Express API and FFmpeg processing worker
- `lib/api-spec`: OpenAPI contract
- `lib/api-client-react` and `lib/api-zod`: generated clients and validation
- `lib/db`: PostgreSQL schema and database access
- `artifacts/mockup-sandbox`: design-preview workspace

## Development

This is a pnpm workspace intended for Linux and Replit's artifact routing.

```sh
pnpm install
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/yapping-helper run dev
```

Use separate terminals or the configured Replit workflows. The frontend and API need the same-origin `/api` routing configured by Replit; the API listens on its configured port.

Configure PostgreSQL, App Storage, and the OpenAI API through environment secrets. Relevant variable names include `DATABASE_URL`, `OPENAI_API_KEY`, `DEFAULT_OBJECT_STORAGE_BUCKET_ID`, `PRIVATE_OBJECT_DIR`, and `PUBLIC_OBJECT_SEARCH_PATHS`. Do not commit values. App Storage uses Replit's runtime identity, so running outside Replit requires adapting storage authentication and routing.

## Checks and production build

```sh
pnpm run typecheck
pnpm --filter @workspace/yapping-helper test
pnpm --filter @workspace/api-server run build
PORT=20200 BASE_PATH=/ pnpm --filter @workspace/yapping-helper run build
```

Artifact production settings live in each artifact's `.replit-artifact/artifact.toml`. The API build bundles the required font and music assets; packaged FFmpeg and FFprobe dependencies must remain available in production.

## Media and exported links

The two background music loops are generated by `artifacts/api-server/scripts/generate-music.mjs` and included as application assets. Font licenses are kept alongside the fonts.

CSV links use the address of the app where you export them. Export from the published app for shareable production links. Deleting or regenerating clips can invalidate previously exported links.

## Repository privacy

This repository is a clean source snapshot, not an export of Replit checkpoint history. User-uploaded videos, rendered samples, transcripts, local session data, and secret values are intentionally excluded. Bundled music and fonts are included because the renderer requires them.
